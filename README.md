
# Sistema de Gerenciamento de Biblioteca

## Descrição

Projeto desenvolvido em Python para realizar o
gerenciamento de uma biblioteca, permitindo o
cadastro, consulta, remoção e controle do estoque
de livros.

## Funcionalidades

- Cadastro de livros.
- Listagem do catálogo.
- Busca por título.
- Remoção de livros.
- Atualização de estoque.
- Relatórios de quantidade por gênero.
- Gráfico de livros por gênero.

## Tecnologias utilizadas

- Python 3
- Git
- GitHub
- Matplotlib

## Instalação

Instale a biblioteca Matplotlib:

pip install matplotlib

## Como executar

Execute o arquivo principal:

python main.py

## Estrutura do projeto

- main.py: menu principal.
- livros.py: classe Livro.
- catalogo.py: funções de gerenciamento.
- relatorios.py: relatórios e gráficos.
